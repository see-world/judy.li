# Judy Li

**Knowledge Governance • Documentation Leadership • AI Transformation**

A personal thought leadership website focused on the intersection of knowledge governance, engineering information governance, technical documentation, knowledge systems, and AI-enabled information experiences.

## About

This site explores how organizations can build trusted, governed, and AI-ready knowledge ecosystems.

Topics include:

- Knowledge Governance
- Engineering Information Governance
- Knowledge Systems
- Technical Documentation Leadership
- Information Governance
- Model Context Protocol (MCP)
- AI Agents
- Retrieval-Augmented Generation (RAG)
- Enterprise Knowledge Architecture

---

## Core Themes

### Knowledge Governance

Building structures, responsibilities, processes, and controls that ensure organizational knowledge remains:

- Accurate
- Trusted
- Accessible
- Maintainable
- Useful

### Engineering Information Governance

Applying governance principles to engineering information throughout the project lifecycle.

Topics include:

- Document Control
- Master Document Lists (MDL)
- Revision Management
- Supplier Documentation
- Configuration Management
- Information Governance

### Knowledge Systems

Transforming information assets into organizational intelligence through:

- Information Architecture
- Content Strategy
- Metadata Models
- Taxonomy Design
- Knowledge Retrieval

### AI & Knowledge

Exploring how governed knowledge enables successful AI adoption.

Topics include:

- AI Readiness
- MCP
- AI Agents
- Enterprise Search
- RAG Architectures
- Intelligent Knowledge Systems
